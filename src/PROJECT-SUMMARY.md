## 🎨 **Design System**

### **"Warm Intelligence" Brand Identity**

**Color Palette:**
- Primary: Soft Purple (#a78bfa)
- Secondary: Emerald Green (#34d399)
- Tertiary: Sky Blue (#60a5fa)
- Background: Deep blue-black (#0a0a0f)
- Text: White (#ffffff) / Zinc gray (#a1a1aa)

**Typography:**
- Font: Inter with OpenType features
- Responsive scaling: 40px mobile → 64px desktop (h1)
- Generous line heights (1.6-1.7)
- Negative letter spacing (-0.02em) on headings

**Effects:**
- Glassmorphism (backdrop-blur-xl)
- Gradient text on headlines
- Soft glows on hover
- Particle systems
- Waveform animations
- Smooth scroll-triggered reveals

**Spacing:**
- Sections: 80px mobile → 160px desktop
- Container: 1280px max-width
- Gutters: 24px mobile → 80px desktop

---

## 📱 **Responsive Design**

### **Breakpoints:**
- Mobile: < 640px (default)
- Tablet: 640-1024px (md:)
- Desktop: 1024px+ (lg:)
- Large: 1440px+ (xl:)

### **Mobile Optimizations:**
✅ Hamburger navigation with slide-down menu
✅ Stacked hero layout with full-width buttons
✅ Swipeable AI helpers carousel (vs desktop full-screen)
✅ Vertical step flow (vs horizontal)
✅ Stacked feature cards (vs 2x2 grid)
✅ Horizontal scroll pricing (vs 3-column grid)
✅ Reduced particle count (30 vs 80)
✅ Disabled parallax effects (battery saving)
✅ Touch-optimized tap targets (44px minimum)
✅ Optimized images and animations
