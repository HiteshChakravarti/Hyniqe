## 🎨 **Color Usage Map**

### **Purple (#a78bfa):**
- Gradient text headlines
- Primary CTA buttons
- Navigation hover states
- Link colors
- Active states
- Icon accents

### **Emerald (#34d399):**
- "Online" status indicators
- Success checkmarks
- Secondary accents
- Step descriptions
- Trust badges

### **Sky Blue (#60a5fa):**
- Gradient midpoints
- Secondary buttons
- Hover effects
- Tertiary accents

### **Dark Backgrounds:**
- Primary BG: #0a0a0f (deep blue-black)
- Cards: #1a1a24 (elevated)
- Sections: #131318 (alternating)

### **Text:**
- Headlines: #ffffff (white)
- Body: #a1a1aa (zinc-400)
- Subtle: #71717a (zinc-500)

## 🎭 **Animation Timeline**

### **Hero (On Load):**
```
0.0s: Particle system starts
0.2s: Badge fades in
0.3s: Headline slides up
0.4s: Description fades in
0.5s: Buttons appear
0.6s: Stats counter up
1.5s: Scroll indicator bounces
```

### **AI Helpers (On Scroll Into View):**
```
0.0s: Section header fades in
0.3s: Character slides in from left
0.5s: Info card slides in from right
0.8s: Stats cards pop in
1.0s: CTA button scales up
```

### **Auto-Advance:**
```
Every 5s: Next AI helper
Smooth fade transition
Direction awareness (left/right)
```

## 📐 **Spacing System**

### **Desktop (1024px+):**
- Section padding: 160px top/bottom
- Container max-width: 1280px
- Container padding: 80px left/right
- Grid gaps: 48px
- Card padding: 32px

### **Mobile (< 640px):**
- Section padding: 80px top/bottom
- Container padding: 24px left/right
- Grid gaps: 24px
- Card padding: 24px

## 🎯 **Interactive Elements**

### **Hover States (Desktop):**
- Buttons: Scale 1.05x + glow
- Cards: Background brightens
- Links: Color shift
- Icons: Scale + color change
- Thumbnails: Opacity 1.0

### **Touch States (Mobile):**
- Buttons: Active background
- Cards: Tap highlight
- Swipe: Momentum scroll
- Accordion: Expand smoothly


### **Button Gradient (Primary CTA):**

### **Background Overlay:**
```css
from-[#a78bfa]/10 via-transparent to-[#34d399]/10
```
