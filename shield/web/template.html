    Check whole projects from the terminal

    The same engine runs as a free, open-source command-line tool with no dependencies. It never runs the code it checks.

    git clone https://github.com/HiteshChakravarti/Hyniqe
cd Hyniqe/shield
python3 -m hyniqe_shield scan ~/.cursor/mcp.json
python3 -m hyniqe_shield scan ./my-skills -f markdown

    Block risky add-ons in pull requests

    Add the GitHub Action and every change to skills, MCP configs or workflows is checked, with findings shown in GitHub code scanning.

    - uses: HiteshChakravarti/Hyniqe/shield@main
  with:
    path: .
    fail-on: dangerous
